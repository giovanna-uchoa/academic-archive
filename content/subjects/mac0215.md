A Ciência Aberta busca tornar a pesquisa mais acessível, transparente e reprodutível, incluindo o software utilizado na produção científica. Nesse contexto, o Software para Pesquisa (_Research Software_) deve ser localizável, bem documentado, licenciado de forma aberta e reprodutível. O uso de software livre reforça esses princípios ao promover transparência, auditabilidade e colaboração, contribuindo para a sustentabilidade de ferramentas científicas.

Este projeto tem como objetivo investigar e sistematizar práticas que orientem a adoção de boas práticas de Engenharia de Software e Ciência Aberta em projetos consolidados de Software para Pesquisa — isto é, aqueles que possuem base de usuários ativa e estrutura funcional madura. Busca-se identificar diretrizes e estratégias que apoiem a transição desses projetos para iniciativas sustentáveis de software livre.

Como estudo de caso, será analisada a plataforma Cortext, uma ferramenta para análise computacional de documentos com mais de mil usuários ativos anuais em cerca de 50 países. Embora utilize bibliotecas de software livre, a plataforma ainda não é distribuída integralmente sob uma licença aberta, o que limita sua aderência aos princípios da Ciência Aberta. Além disso, sua base de código apresenta desafios relacionados à manutenibilidade e à modularidade, dificultando contribuições externas e a expansão de sua comunidade de desenvolvimento.

### Justificativa

Modernizar um sistema legado envolve não apenas atualizar linguagens ou bibliotecas, mas também aplicar técnicas sistemáticas de refatoração com o objetivo de melhorar a estrutura interna do software sem alterar seu comportamento externo (Fowler et al., 2018). A refatoração busca reduzir dívidas técnicas acumuladas e preparar o sistema para evolução sustentável, tornando o código mais legível, modular, testável e adaptável a novos contextos de uso.

Essa prática é especialmente relevante para softwares de pesquisa, pois permite que métodos científicos incorporados em código sejam auditados, reutilizados e recombinados por outros pesquisadores — requisitos fundamentais da Ciência Aberta (Barker et al., 2022; Wilkinson et al., 2016).

Nesse contexto, a proposta contribui cientificamente ao aplicar e documentar o processo de modernização em uma plataforma real e amplamente utilizada, gerando evidências empíricas sobre a aplicação de práticas de engenharia de software em contextos interdisciplinares. O projeto possui impacto direto na sustentabilidade e na reprodutibilidade de infraestruturas digitais de pesquisa, um tema de crescente relevância na comunidade científica internacional.

Além disso, ao integrar práticas de refatoração, testes automatizados e licenciamento livre, o projeto contribui para a discussão sobre o reconhecimento do software como um artefato relevante na produção do conhecimento científico — um desafio ainda presente na maioria das áreas.

### Sobre o Projeto

O progresso deste projeto pode ser acompanhado por meio das contribuições realizadas no ecossistema da plataforma Cortext, especialmente via _pull requests_ submetidos ao repositório oficial.

A participação ativa junto à comunidade, incluindo a observação das interações e das revisões de código, permite compreender o fluxo colaborativo de desenvolvimento e identificar aspectos sociotécnicos relevantes. As contribuições são realizadas a partir de um _fork_: [**gitlab.com/cortext-usp**](https://gitlab.com/cortext-usp), garantindo maior controle, transparência e rastreabilidade das modificações propostas.

Esse processo também serve como instrumento de documentação prática da evolução do projeto, evidenciando as decisões técnicas adotadas, os desafios encontrados e as estratégias utilizadas para alinhamento com princípios de Engenharia de Software e Ciência Aberta.
